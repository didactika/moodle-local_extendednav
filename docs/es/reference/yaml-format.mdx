Un archivo de importación es un archivo YAML con una lista `nodes`. Cada entrada describe un elemento con los campos siguientes. Todos los campos salvo `nodekey` son opcionales, y los campos vacíos de un elemento de Moodle conservan los valores de Moodle.

El mismo formato contiene una navegación o todas. Un archivo exportado empieza además con dos claves:

| Clave | Descripción |
|---|---|
| `format` | La versión del formato, `2` |
| `navigations` | Para cada navegación del archivo, `enabled: 1` cuando sus cambios se aplican y `enabled: 0` cuando no. Al importar, cada navegación se activa o desactiva como indica. Un archivo sin esta clave deja cada navegación como está |

## Campos de un nodo

| Campo | Descripción |
|---|---|
| `nodekey` | Clave del elemento, única dentro de su menú. Use la clave de un elemento de Moodle (por ejemplo `myhome`) para cambiarlo |
| `menu` | Navegación del elemento: `primary`, `usermenu`, `frontpage` (página principal del sitio), `course`, `category`, `preferences` (la página Preferencias), `admin` (administración del sitio), o `mod_` y el nombre de un módulo para un tipo de actividad (`mod_forum`, `mod_assign`). Es la navegación elegida en la página de gestión cuando se omite. Un archivo de una versión anterior a la 2.0 puede indicar `activity`, la navegación única de todas las actividades: un elemento de Moodle va a cada tipo que lo tiene, y un elemento añadido va a todos los tipos |
| `native` | `1` para un elemento de Moodle. Un elemento de Moodle que este sitio no tiene se omite con un aviso |
| `order` | Posición del elemento en su navegación, siendo 1 la primera. En la administración del sitio, su posición entre las categorías y páginas de su categoría. Al importar, un elemento sin ella conserva su lugar, o va al final cuando es nuevo |
| `title` | Texto que se muestra. Vacío en un elemento de Moodle conserva el título de Moodle |
| `tooltip` | Texto que se muestra al pasar el cursor sobre el enlace |
| `url` | Destino: una ruta de este sitio (por ejemplo `/course/view.php?id=2`) o una URL completa |
| `icon` | Clase de FontAwesome (por ejemplo `fa-book`) o icono de Moodle (por ejemplo `i/home`). `none` quita el icono |
| `visibility` | `1` visible para todos, `2` restringido por los roles indicados, las restricciones de acceso o ambos, `0` no visible |
| `roles` | Nombres cortos de rol separados por comas (por ejemplo `editingteacher,teacher`). Se usa cuando `visibility` es `2` |
| `blockaccess` | `1` para bloquear la URL a los usuarios que no pueden ver el elemento, `0` en caso contrario. Solo se usa cuando `visibility` es `0` o `2` |
| `langs` | Códigos de idioma separados por comas (por ejemplo `es,pt_br`). El elemento solo se muestra para esos idiomas. Vacío significa todos los idiomas |
| `parentkey` | Clave del elemento padre, para mostrar este elemento en su submenú. En la administración del sitio, la clave de la categoría en la que está el elemento |
| `display` | Cómo se abre el enlace: `0` ventana actual, `1` ventana nueva, `2` ventana emergente |
| `popupwidth`, `popupheight` | Ancho y alto de la ventana emergente en píxeles, de 100 a 9999. Se usan cuando `display` es `2` |
| `scope` | Aquello para lo que el nodo es una excepción: `category:Padre / Nombre`, `course:nombrecorto`, `activity:nombre corto del curso/número de ID` (o `activity:nombre corto del curso/#número de la actividad`) o `user:nombre de usuario`. Vacío significa todo el sitio. Las excepciones de un curso viajan en la copia de seguridad del curso; un archivo puede seguir nombrando uno. Una categoría, un curso, una actividad o un usuario que el sitio no tiene se omite con un aviso |
| `availability` | Restricciones de acceso de Moodle, en JSON, como las guarda la restricción de acceso de una actividad. Se usa cuando `visibility` es `2`; un archivo de una versión anterior con `visibility: 1` y restricciones de acceso se importa como `2`. Consulte [Mostrar un nodo a algunas personas o durante un tiempo](page:guides/conditions) |
| `placement` | Dónde va un nodo de una navegación secundaria: `0` donde lo pone Moodle, `1` siempre en el menú Más, `2` nunca en el menú Más |
| `hideadmins` | `1` para ocultar el nodo también a los administradores del sitio |

## Ejemplo

```yaml
format: 2
navigations:
  primary:
    enabled: 1
nodes:
  - nodekey: help_en
    menu: primary
    order: 24
    title: "Help"
    tooltip: "Guides and contact details"
    url: "/mod/page/view.php?id=13"
    icon: "fa-circle-question"
    visibility: 1
    langs: "en"
  - nodekey: guide_teachers
    menu: primary
    title: "Guide for teachers"
    url: "/mod/page/view.php?id=12"
    visibility: 2
    roles: "editingteacher,teacher"
    blockaccess: 1
    parentkey: "guides"
```

La página de importación ofrece también un archivo de ejemplo para descargar.
