Esta tarea lleva unos diez minutos. Añade un elemento a la navegación principal.

<Steps>
1. Vaya a **Administración del sitio > Apariencia > Extended navigation > Gestionar la navegación**.
2. Seleccione **Añadir nodo**.
3. Escriba una **Clave del nodo** (letras, números, guiones bajos y guiones), un **Título** y una **URL**, como `/course/index.php`.
4. Elija un **Icono** si lo desea y mantenga **Visible para todos**.
5. Guarde.
</Steps>

<Screenshot src="asset:manage-primary.webp" alt="La página de gestión, con el nuevo elemento entre los elementos de la navegación principal" caption="El nuevo elemento aparece en la lista y en el menú." url="/local/extendednav/manage.php" />

El elemento se muestra al instante en la navegación principal de todos los usuarios con sesión iniciada.

<Screenshot src="asset:primary-navigation.webp" alt="La navegación principal con los elementos Training, Guides y Help añadidos por el plugin" caption="La navegación principal con los elementos añadidos." url="/my/" />

> [!TIP]
> Para ver el cambio como otro tipo de usuario, dé al elemento la visibilidad **Restringido** y elija los roles que pueden verlo. Consulte [Cómo se muestra un elemento](page:concepts/how-an-item-is-shown).
