Extended navigation (`local_extendednav`) is a Moodle local plugin that lets administrators manage the two menus every user sees: the primary navigation at the top of the page and the user menu under the picture of the user. Add items, rename, re-link, reorder, nest or hide the items of Moodle, show items only to some roles or languages, and stop users from opening the pages of the items they cannot see.

<Screenshot src="asset:manage-primary.webp" alt="The page that manages the primary navigation, with one row per item, its visibility, icon, node key and URL" caption="The management page: every item of the primary navigation, with its visibility and actions." url="/local/extendednav/manage.php" />

> [!IMPORTANT]
> **The site needs a theme based on Boost.** The plugin changes the primary navigation and the user menu that Boost and its child themes display. The themes that do not use them, such as Classic, show no changes.

> [!NOTE]
> The items of Moodle stay translated. Leave the title and the URL of an item of Moodle empty and the plugin keeps using the values of Moodle; the form shows them as placeholders.

## Why it exists

The menus of Moodle are the same for everyone and only partly configurable. Extended navigation gives each item its own visibility, roles, languages and blocking rule, so students, teachers and staff each see the navigation that fits them.

## What it does

<FeatureGrid>
  <Feature icon="menu-rounded" title="Two menus">The primary navigation and the user menu, each with the items of Moodle listed and editable.</Feature>
  <Feature icon="account-tree-rounded" title="Submenus">One level of submenus in both menus. A parent moves with its submenu items.</Feature>
  <Feature icon="drag-indicator-rounded" title="Ordering by dragging">With a move dialog that works with the keyboard.</Feature>
  <Feature icon="tune-rounded" title="Options of each item">Title, tooltip, URL, icon, and how the link opens: in the current window, in a new window or in a pop-up.</Feature>
  <Feature icon="verified-user-rounded" title="Safety checks">The form refuses the changes that would leave every user without a landing page.</Feature>
  <Feature icon="history-rounded" title="Activity log">Who created, changed or deleted each item, and when.</Feature>
</FeatureGrid>

Besides, the items of **Custom menu items** and **User menu items** of Moodle are imported and kept in sync, the whole navigation can be copied between sites with YAML files, and the capability `local/extendednav:manage` lets other roles manage it.
