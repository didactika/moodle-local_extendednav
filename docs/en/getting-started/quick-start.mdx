title: Quick start
summary: Add an item to the primary navigation and see it in the menu.

---

This task takes about ten minutes. It adds one item to the primary navigation.

<Steps>
1. Go to **Site administration > Appearance > Extended navigation > Manage navigation**.
2. Select **Add node**.
3. Write a **Node key** (letters, numbers, underscores and hyphens), a **Title** and a **URL**, such as `/course/index.php`.
4. Choose an **Icon** if you want one, and keep **Visible to everyone**.
5. Save.
</Steps>

<Screenshot src="asset:manage-primary.webp" alt="The management page, with the new item among the items of the primary navigation" caption="The new item appears in the list and in the menu." url="/local/extendednav/manage.php" />

The item is shown at once in the primary navigation of every logged-in user.

<Screenshot src="asset:primary-navigation.webp" alt="The primary navigation with the items Training, Guides and Help added by the plugin" caption="The primary navigation with the added items." url="/my/" />

> [!TIP]
> To see the change as another kind of user, give the item the visibility **Restricted** and choose the roles that may see it. See [How an item is shown](page:concepts/how-an-item-is-shown).
