**Requirements:** Moodle 4.5 to 5.2, with the PHP version your Moodle release requires, and a theme based on Boost. Moodle 5.3 has a line of its own with the same features.

| Moodle | Branch | Releases |
|---|---|---|
| 4.5 to 5.2 | `MOODLE_400_STABLE` | `X.Y.Z-m405` |
| 5.3 | `main` | `X.Y.Z-m503` |

<Tabs>
  <TabItem label="From a release">
    Download the latest release ZIP, go to **Site administration > Plugins > Install plugins**, upload the file and follow the prompts.
  </TabItem>
  <TabItem label="From Git">
```bash
cd /path/to/moodle
# Moodle 4.5 and 5.0
git clone -b MOODLE_400_STABLE https://github.com/didactika/moodle-local_extendednav.git local/extendednav
# Moodle 5.1 and 5.2
git clone -b MOODLE_400_STABLE https://github.com/didactika/moodle-local_extendednav.git public/local/extendednav
php admin/cli/upgrade.php
```
  </TabItem>
</Tabs>

The installation creates one row for each of the items of Moodle and imports the items already defined in **Custom menu items** and **User menu items**. The next step is to [change a first item](page:getting-started/quick-start).
