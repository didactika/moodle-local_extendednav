An import file is a YAML file with a `nodes` list. Each entry describes one item with the fields below. Every field except `nodekey` is optional, and the empty fields of an item of Moodle keep the values of Moodle.

The same format holds one navigation or every navigation. An exported file also starts with two keys:

| Key | Description |
|---|---|
| `format` | The version of the format, `2` |
| `navigations` | For each navigation of the file, `enabled: 1` when its changes are applied and `enabled: 0` when they are not. On import, each navigation is turned on or off as it says. A file without it leaves every navigation as it is |

## Fields of a node

| Field | Description |
|---|---|
| `nodekey` | Key of the item, unique within its menu. Use the key of an item of Moodle (for example `myhome`) to change it |
| `menu` | Navigation of the item: `primary`, `usermenu`, `frontpage` (site home), `course`, `activity`, `category` or `admin` (site administration). It is the navigation chosen on the management page when omitted |
| `native` | `1` for an item of Moodle. An item of Moodle that this site does not have is left out with a warning |
| `order` | Position of the item in its navigation, 1 being the first. In the site administration, its position among the categories and pages of its category. On import, an item without it keeps its place, or goes last when it is new |
| `title` | Display text. Empty on an item of Moodle keeps the title of Moodle |
| `tooltip` | Text shown when hovering over the link |
| `url` | Destination: a path of this site (for example `/course/view.php?id=2`) or a full address |
| `icon` | FontAwesome class (for example `fa-book`) or icon of Moodle (for example `i/home`). `none` removes the icon |
| `visibility` | `1` visible to everyone, `2` restricted to the roles listed, `0` not visible |
| `roles` | Role shortnames separated by commas (for example `editingteacher,teacher`). Used when `visibility` is `2` |
| `blockaccess` | `1` to block the URL for the users who cannot see the item, `0` otherwise. Only used when `visibility` is `0` or `2` |
| `langs` | Language codes separated by commas (for example `es,pt_br`). The item is only shown for these languages. Empty means every language |
| `parentkey` | Key of the parent item, to show this item in its submenu. In the site administration, the key of the category the item is in |
| `display` | How the link opens: `0` current window, `1` new window, `2` pop-up |
| `popupwidth`, `popupheight` | Width and height of the pop-up in pixels, from 100 to 9999. Used when `display` is `2` |
| `scope` | The category or the course the node is an exception for: `course:shortname` or `category:Parent / Name`. Empty means the whole site |
| `placement` | Where a node of a secondary navigation goes: `0` where Moodle puts it, `1` always in the More menu, `2` never in the More menu |
| `hideadmins` | `1` to hide the node from site administrators too |

## Example

```yaml
format: 2
navigations:
  primary:
    enabled: 1
nodes:
  - nodekey: help_en
    menu: primary
    order: 24
    title: "Help"
    tooltip: "Guides and contact details"
    url: "/mod/page/view.php?id=13"
    icon: "fa-circle-question"
    visibility: 1
    langs: "en"
  - nodekey: guide_teachers
    menu: primary
    title: "Guide for teachers"
    url: "/mod/page/view.php?id=12"
    visibility: 2
    roles: "editingteacher,teacher"
    blockaccess: 1
    parentkey: "guides"
```
