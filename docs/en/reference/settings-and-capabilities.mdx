## Turn a navigation on or off

The plugin has no settings page: everything is on the management page, at **Site administration > Appearance > Extended navigation > Manage navigation**.

The button next to the name of each navigation applies its changes or not. It shows **On**, in green, while the changes are applied: press it to turn them off. It then shows **Off**, in grey, and the column of the navigations marks that navigation as **Off**: press the button to apply the changes again. While a navigation is off, Moodle draws it as it does without the plugin, and its nodes and their order are kept. The other navigations keep their changes.

| Navigation | When it is off |
|---|---|
| Primary navigation | Moodle shows its primary navigation, and no address is blocked |
| User menu | Moodle shows its user menu |
| Site home, course, activity, category | Moodle shows its own navigation on those pages |
| Site administration | Moodle shows its own tree of categories and pages |

Whether a node is also hidden from administrators is decided in the form of each node. See [Administrators see every node](page:concepts/administrators-see-everything).

## Capabilities

| Capability | Default roles | Allows the user to |
|---|---|---|
| `local/extendednav:manage` | None | Manage the items, import, export and see the activity log, in the system context |
| `local/extendednav:managecontext` | Manager | Change the navigations of a category, a course or an activity, and of everything inside it, from its page **Navigation** |

The users who have this capability find the management page in the same place as the administrators.

> [!WARNING]
> Whoever holds `local/extendednav:manage` decides the menu of every user and which pages are blocked. Give it only to people you would trust with the navigation of the site.

## Scheduled task

**Find the items of the navigation of each kind of activity** runs once a day, at night. It builds, as an administrator, the navigation of the most recent activities of each kind and lists the items Moodle and its plugins add to them, so they can be changed before anyone opens such an activity. It sends nothing to the browser and changes nothing on the activities. Its schedule is set in **Site administration > Server > Tasks > Scheduled tasks**.

## Privacy

The plugin stores navigation items, not personal data, and implements the Privacy API as a null provider.

## Backup

The nodes of the site and the exceptions of the categories are configuration of the site: use the YAML export to copy them. The exceptions of a course and of its activities are part of the backup of the course, and of the backup of each activity.
