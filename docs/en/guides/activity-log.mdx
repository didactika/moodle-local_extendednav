---
title: Activity log
summary: See who created, changed or deleted each item, and when.
order: 60
---

On the management page, select **Activity log**. The two tabs show the log of the primary navigation and the log of the user menu.

<Screenshot src="asset:activity.webp" alt="The activity log of the primary navigation, with the time, the user, the action and the description of each change" caption="The activity log: one row per change." url="/local/extendednav/activity.php" />

Each row shows the time, the user, the action (created, updated or deleted), the event and the description. Filter by a period and by action, and sort by time.

The changes of the items are recorded as events in the log store of the site, which the activity log reads, so they follow the retention settings of your log.
