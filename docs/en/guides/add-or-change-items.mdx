Go to **Site administration > Appearance > Extended navigation > Manage navigation**. The column to the left chooses the navigation; **Primary navigation** and **User menu** list the items of each menu, with a search by title, node key or URL and a menu that narrows the list by visibility. For the navigations of a course, an activity, a category and the administration, see [Change the other navigations](page:guides/other-navigations).

<Screenshot src="asset:manage-usermenu.webp" alt="The tab of the user menu, with the items of Moodle and the items added by the plugin" caption="The tab of the user menu." url="/local/extendednav/manage.php" />

You need the capability `local/extendednav:manage`, or to be a site administrator.

## Add or change an item

Select **Add node**, or the edit icon of an item. The form is in sections, in the order in which an item is usually decided. A field that is required is marked, and a value that is not valid is explained under its field when you save.

| Section | Fields |
|---|---|
| **Node** | The **Node key** of a new item (letters, numbers, underscores and hyphens), its **Title** and its **URL**. For an item of Moodle, a notice at the top of the section says so: change only what you need, as the empty fields keep the values of Moodle, shown as placeholders |
| **Look and opening** | A **Tooltip** and an **Icon**: **Choose icon** opens a searchable list of icons of Moodle and FontAwesome, and the search also accepts a FontAwesome class or a Moodle icon that is not in the list. For an item of Moodle, **Use the Moodle icon** keeps the icon Moodle gives it and **No icon** removes it. Then and how it opens with **Display**: **Current window**, **New window** or **Pop-up**, with its width and height (620 × 450 pixels by default) |
$1. A node that is **Not visible** asks for no language and no restriction, as nobody sees it |
| **Where it goes** | The **Parent**, to show the item in its submenu. In the navigations of the site home, a course, an activity and a category, it decides whether the node stays where Moodle puts it, always in the **More** menu or in the bar. In the site administration, the **Category** of a link of your own, which is required |

## Delete an item

Select the delete icon of an item. An item of Moodle that is deleted comes back as a new item if Moodle adds it again. See [The items of Moodle](page:concepts/moodles-own-items).

## What the form refuses

The form refuses the changes that would leave every user without a landing page, and Site administration can never be hidden or nested.

## Check the result

The primary navigation and the user menu show the change at once. An item that is limited to languages appears only to the users of those languages.
