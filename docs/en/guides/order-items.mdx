---
title: Order the items
summary: Change the position of the items by dragging them, or with a list of positions.
order: 40
---

Drag an item by the handle in the **Order** column, or select the handle to open a list of positions that works with the keyboard.

<Screenshot src="asset:manage-primary.webp" alt="The management page, with the handle of each item in the Order column" caption="The Order column has a handle for each item." url="/local/extendednav/manage.php" />

- Moving a parent moves its submenu items with it.
- A submenu item only moves among its siblings.
- An item that leaves its parent stays right below the group of that parent.
- The ordering is off while a filter is applied. Use **Clear** to order again.

The order of the list is the order of the menu, and an exported file keeps it: every item has its position in the field `order`.
